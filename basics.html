Переменные в Python

Переменные - это контейнеры для хранения данных. В Python не нужно объявлять тип переменной.

Что такое переменная?

Переменная — это именованная область памяти, которая хранит данные. Представьте её как коробку с названием, в которой лежит значение.

age 25
name "Alice"

Примеры использования

# Простые переменные
age = 25
name = "Alice"
height = 1.75
is_student = True

# Множественное присваивание
x, y, z = 1, 2, 3

# Динамическая типизация
variable = 10      # Сначала число
variable = "text"  # Теперь строка

print(f"Имя: {name}, Возраст: {age}")
Вывод: Имя: Alice, Возраст: 25

Работа с типами данных

# Проверка типа
print(type(42))        # <class 'int'>
print(type("Hello"))   # <class 'str'>

# Преобразование типов
number = "123"
converted = int(number)
print(f"Преобразовано: {converted}")  # Преобразовать в число

# Операции со строками
text = "Python"
print(text.upper())    # PYTHON
print(len(text))       # 6

# Работа со списками
fruits = ["apple", "banana"]
print("Исходный список:", fruits)
fruits.append("orange")
print("После добавления:", fruits)
print("Первый элемент:", fruits[0])
print("Все элементы списка:")
for fruit in fruits:
    print(f" - {fruit}")

Условные конструкции

Управление потоком выполнения программы на основе условий.

Примеры условий

# Простое условие
age = 18
if age >= 18:
    print("Совершеннолетний")
else:
    print("Несовершеннолетний")

# Множественные условия
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"

print(f"Оценка: {grade}")

# Сложные условия
temperature = 25
is_sunny = True

if temperature > 20 and is_sunny:
    print("Идеальная погода для прогулки!")

Циклы в Python

Повторение действий - основа автоматизации в программировании.

Цикл for

Для перебора последовательностей

# Перебор списка
fruits = ["apple", "banana", "orange"]
for fruit in fruits:
    print(fruit)

# Цикл с range
for i in range(5):
    print(f"Итерация {i}")

# Перебор словаря
person = {"name": "Alice", "age": 25}
for key, value in person.items():
    print(f"{key}: {value}")

Цикл while

Пока условие истинно

# Простой цикл while
count = 5
while count > 0:
    print(count)
    count -= 1
print("Старт!")

# Цикл с break
while True:
    user_input = input("Введите 'stop' для выхода: ")
    if user_input == "stop":
        break
    print(f"Вы ввели: {user_input}")
