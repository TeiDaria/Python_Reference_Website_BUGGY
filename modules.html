Что такое модуль?

Модуль — это файл с расширением .py, содержащий определения и инструкции Python. Модули позволяют организовать код логически и повторно использовать его.

Что такое пакет?

Пакет — это способ структурирования пространства имен модулей с помощью "точечных имен модулей". Пакет содержит несколько модулей в папке с файлом __init__.py.

Что такое библиотека?

Библиотека — это коллекция модулей и пакетов, предназначенная для решения определенного класса задач (научные вычисления, веб-разработка, анализ данных и т.д.).

Установка библиотек

Менеджер пакетов pip

Python использует pip (Package Installer for Python) для установки и управления пакетами из PyPI (Python Package Index).

Установка библиотеки:

pip install numpy

Установка конкретной версии:

pip install pandas==1.5.0

Установка из requirements.txt:

pip install -r requirements.txt

Исследуйте библиотеки

Лучшие практики работы с библиотеками

01

Виртуальные окружения

Всегда используйте виртуальные окружения для изоляции зависимостей проекта.

python -m venv myenv
02

Файл requirements.txt

Сохраняйте список зависимостей в файле requirements.txt для воспроизводимости.

pip freeze > requirements.txt
03

Семантическое версионирование

Указывайте версии библиотек для избежания конфликтов при обновлениях.

numpy>=1.21.0,<2.0.0
04

Регулярное обновление

Регулярно обновляйте зависимости для получения исправлений безопасности и новых функций.

pip install --upgrade package-name
